## 2. 5대 대표 충돌 사례 정밀 분석 (Forensic Case Studies)

### 사례 1: Page 1 KPI 지표 1 — [균열밀도 (CDI)] vs [0.031%]

```text
[ Figma / Canonical IR ]
y = 457.30 pt ┌────────────────────────────────────────┐
              │ ID: 7:980 "균열밀도 (CDI)" (w=53.98, h=9.75)│
y = 467.06 pt └────────────────────────────────────────┘
              ◄── Vertical Gap = 6.00 pt ──►
y = 473.06 pt ┌────────────────────────────────────────┐
              │ ID: 7:981 "0.031%" (w=55.48, h=17.99) │
y = 491.05 pt └────────────────────────────────────────┘

[ HWPX with lineWrap="BREAK" in Hancom 2024 Viewer ]
y = 457.30 pt ┌────────────────────────────────────────┐
              │ Line 1: 균열밀도                       │
y = 468.41 pt │ Line 2: (CDI) ─────────┬───────────────┼───► 높이 9.75pt 초과!
y = 473.06 pt │        ▲▲▲▲▲▲▲▲▲▲▲▲▲▲  │0.031%         │◄── 3.6pt 영역 글자 중첩 충돌!
              └────────────────────────┴───────────────┘
```

1. **상위 요소 (ID: `7:980`, "균열밀도 (CDI)")**:
   - Figma/Canonical IR: `x: 52.48 pt, y: 457.30 pt, width: 53.98 pt, height: 9.75 pt`
   - 글꼴: 8.25 pt, 행간: 11.13 pt
   - 텍스트: `"균열밀도 (CDI)"` (10자)
   - 텍스트 단일행 필요 폭: 한글 4자(33.0pt) + 공백(4.1pt) + 영문/괄호 5자(22.7pt) = **약 59.8 pt**
   - **기하학적 결함**: 박스 폭(`53.98 pt`)이 텍스트 단일행 폭(`59.8 pt`)보다 **5.82 pt 협소함**.
2. **하위 요소 (ID: `7:981`, "0.031%")**:
   - Figma/Canonical IR: `x: 52.48 pt, y: 473.06 pt, width: 55.48 pt, height: 17.99 pt`
3. **물리적 간격 (Vertical Gap)**:
   - 상위 박스 바닥 = `457.30 + 9.75 = 467.06 pt`
   - 하위 박스 상단 = `473.06 pt`
   - **여백 = 6.00 pt (극도로 협소)**
4. **한컴 뷰어 충돌 메커니즘**:
   - `hwpxCanvasRenderer.ts`가 `lineWrap="BREAK"`를 지정함.
   - 한컴 뷰어는 박스폭 53.98pt에 맞춰 `"균열밀도"`와 `"(CDI)"`로 강제 2행 줄바꿈.
   - 2행 렌더링에 필요한 높이 = `11.13 pt × 2 = 22.26 pt`.
   - 그러나 `<hp:rect>`의 높이는 `9.75 pt`로 고정되어 있음.
   - 2행 `(CDI)` 텍스트가 `y = 457.30 + 11.13 = 468.43 pt`에서 시작하여 `476.68 pt`까지 그려짐.
   - 이는 하위 요소의 시작 지점인 `473.06 pt`를 **3.62 pt 침범하여 "0.031%" 숫자 위로 글자가 겹쳐 인쇄됨**.

## 4. 기하학적 근본 결론 (Forensic Conclusion)

1. **충돌의 1차 원인**: Figma 원본 디자인에서 단일행 라벨 텍스트박스들의 `width`가 실제 글자 렌더링에 필요한 물리적 폭보다 **5~15pt 좁게 정의**되어 있습니다.
2. **Figma에서의 외형**: Figma 캔버스는 AutoLayout이나 텍스트 오버플로우를 자유롭게 허용하므로 디자이너의 눈에는 단일행으로 보입니다.
3. **HWPX에서의 파국**: `lineWrap="BREAK"`가 적용되면, 한컴오피스는 폭이 부족한 모든 라벨을 예외 없이 2줄로 쪼갭니다.
4. **수직 마진의 한계**: 직하단 요소와의 수직 마진이 불과 **6.0pt**에 불과하므로, 2줄로 늘어난 순간(+12.5pt ~ +22.5pt) **수학적으로 겹침이 100% 필연적으로 발생**합니다.
