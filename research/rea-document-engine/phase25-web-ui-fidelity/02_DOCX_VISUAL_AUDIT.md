## 3. 우선 분석 대상 7개 화면 심층 감사

### 1) 디자인 가이드 및 컬러·타이포그래피 (Page 1)
- **증상**: `디자인 시스템 1`과 `디자인 시스템 2`의 모든 텍스트, 컬러 카드, 버튼 칩이 완전히 동일한 좌측 상단(0, 0) 기준 좌표에 겹쳐 렌더링됨.
- **원인**: DOCX Canvas Renderer에서 두 페이지의 크기(1440×810pt)가 동일하여 `nextDiffers` 플래그가 `false`가 됨. 이로 인해 두 화면 사이에 OpenXML `<w:sectPr>`가 생성되지 않아 Word가 두 화면의 VML 객체들을 1페이지 캔버스에 동시에 배치함.

### 2) 사업현황 목록 화면 (Page 3, 7)
- **증상**: 좌측 통계 카드(1339, 44, 4, 1291), 검색 바, 사업목록 카드, 우측 전국 지도(Leaflet 배경)가 비교적 충실히 렌더링됨.
- **문제점**: 페이지 규격이 20인치(1440pt)로 설정되어 일반 프린터 인쇄가 불가능하며, Word 화면에서 40% 이하로 축소해야 전체를 볼 수 있음.

### 3) 사업장 검색 및 선택 (Page 9, 13)
- **증상**: Page 9(Step 1)는 모달 형태가 비교적 깔끔하나, Page 13(Step 2)에서는 화면 전체가 이전 화면(사업목록 클릭 시)과 100% 겹쳐 완전히 붕괴됨.
- **원인**: Page 12와 13 사이 섹션 분리 누락.

### 4) 필터와 입력 폼 (Page 8, 10)
- **증상**: Page 10의 체크박스 그룹(지역 선택)에서 서울, 경기, 인천 등이 정갈하게 나오나 페이지 폭이 5.25인치로 지나치게 작음. Page 8의 필터 팝업에서는 모달 외부 배경이 좌우로 잘림.

### 5) 사업정보 수정 화면 (Page 11, 12)
- **증상**: 폼 필드("사업명", "주소", "시공사", "공사구조") 배치 양호하나, Page 11에서 디자이너가 배치한 검토 메모("margin", "height")가 인풋 요소 위로 덮어써짐.

### 6) 사업 상세 대시보드 (Page 5, 14)
- **증상**: Page 5에서 중간 테이블 행(106동~115동)이 증발함. Page 14에서는 인풋박스 라벨("시작일:", "종료일:")이 인풋 박스 테두리와 충돌함.
- **원인**: Word의 폰트 렌더링이 Figma 브라우저 엔진보다 약 1~2px 넓어 single-line auto-width 텍스트박스에서 강제 줄바꿈이 발생하거나 테두리를 침범함.

### 7) 촬영계획 화면 (Page 6, 15)
- **증상**: 건물 다각형(Polygon)과 꼭짓점 번호(1~8번) 마커가 완벽하게 벡터 렌더링됨. 그러나 좌측 피드백 적색 글씨가 버튼과 겹침.

## 4. 결함 근본 원인 분류 (Taxonomy)

1. **A. OpenXML 섹션 분리 누락 결함 (CRITICAL)**:
   - `nextDiffers` 조건 오류로 동일 크기 페이지 간 섹션 브레이크 생략 ➡️ 2~3개 화면이 1장에 겹쳐 렌더링됨 (Page 1, Page 13).
2. **B. 비문서 오버레이/가이드 미필터링 결함 (HIGH)**:
   - 최상위 `GROUP`(`📏 Container`)을 무조건 페이지로 수집 ➡️ 70인치 초대형 검은색 빈 페이지 생성 (Page 4).
3. **C. 페이지 스케일링 전략 불일치 (HIGH)**:
   - 1920×1080 웹 와이드 화면을 A4로 맞추지 못하고 0.75 배율(20인치 와이드)로 떨어뜨려, 문서 내 페이지 크기가 5.25인치부터 70인치까지 극심하게 불균형함.
4. **D. 텍스트박스 줄바꿈 및 여백 보정 부재 (MEDIUM)**:
   - Figma 단일행 자동너비(Auto-width) 텍스트박스에 마진 여유가 없어 Word에서 1단어 강제 줄바꿈 또는 겹침 발생.
