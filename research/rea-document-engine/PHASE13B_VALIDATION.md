# Phase 13B: Canvas 듀얼 엔진 검증 보고서 (Validation Report)

## 1. 개요

본 보고서는 Phase 13B에서 수행된 Canvas IR 기반 DOCX/HWPX 듀얼 엔진의 호환성, 라운드트립 무손실성, 실제 Office COM 연동 및 회귀 검증 결과를 종합한다.

### 2.2 누락 요소 100% 복구 상세 원인 분석
- **문제점**: Phase 13A에서 각 보고서별로 6~10개의 라인 요소가 누락되었음.
- **원인 분석**:
  1. VML의 `<v:line>`은 자가 닫힘 태그(`/>`) 형식을 취함. 기존 정규식은 `</v:line>` 닫는 태그를 필수로 요구하여 모든 라인 분할선이 무시됨.
  2. `<v:roundrect>` 내부 `<w:jc w:val="left"/>` 등 자가 닫힘 단락 태그를 만나 정규식 매칭이 중간에 조기 차단되는 현상 발생.
  3. 전체 매칭 블록에 대한 속성 추출 시 자식 태그(`<v:textbox style="...">`)가 부모 태그(`<v:rect style="...">`)의 너비/높이 속성을 덮어쓰는 간헐적 좌표 왜곡 발생.
- **해결 결과**:
  1. 정규식에서 자가 닫힘 태그와 쌍 태그를 명확히 분리 매칭.
  2. 부모 여는 태그(`<v:...>`)만을 대상으로 1차 속성을 파싱하여 덮어쓰기 원천 차단.
  3. 3종 보고서 전원에 걸쳐 100.0% 요소 복원 및 무손실 라운드트립 달성.

### 3.2 Word 렌더링 시각적 품질 분석
- VML `<v:rect>`, `<v:roundrect>`, `<v:line>` 요소가 Word 네이티브 캔버스 상에 정확한 절대좌표(`pt`)로 배치됨.
- 각 페이지 하단의 `<w:p><w:r><w:br w:type="page"/></w:r></w:p>` 브레이크와 정확히 동기화되어 페이지 밀림 현상 0건.
- `Pretendard`, `맑은 고딕` 등 한글 서체가 `w:eastAsia`에 정밀 바인딩되어 Word가 대체 폰트로 임의 전환하지 않고 정규 메트릭으로 렌더링함.

## 4. Hancom Office COM 및 HWPX 적합성 검증

### 4.1 COM 자동화 환경 조사
- **COM ProgID**: `HWPFrame.HwpObject` 레지스트리 등록 확인 완료.
- **보안 승인 대화상자 제약**:
  - 한글과컴퓨터의 기본 보안 정책 상, 외부 COM 클라이언트가 문서를 로드하거나 접근할 때 대화상자(*"외부 프로그램에서 한글 문서에 접근하려고 합니다. 접근을 허용하시겠습니까?"*)가 강제 모달로 표시됨.
  - 무인 배치(CI/CD, 백그라운드 서비스) 환경에서는 사용자가 '허용' 버튼을 수동 클릭하지 않으면 프로세스가 대기 상태에 머무름.
  - 무인 자동화를 완전 지원하려면 Windows 레지스트리(`HKCU\Software\HNC\HwpAutomation\Modules`)에 공식 등록된 보안 모듈(`FilePathCheckDLL`)이 요구됨.

### 4.2 OWPML (KS X 6101) 표준 적합성 검증
무인 실행의 대화상자 제약과 별개로, 생성된 HWPX 파일의 구조적 완성도를 전수 검증함:
1. **ZIP 컨테이너 구조**:
   - `mimetype` (압축 없이 첫 번째 엔트리로 배치, `application/hwp+zip`)
   - `META-INF/container.xml` (rootfile `Contents/content.hpf` 지정)
   - `Contents/content.hpf` (OPF 메타데이터, 매니페스트, 스파인 일치)
   - `Contents/header.xml` (문서 서식 및 7개 언어군 fontfaces)
   - `Contents/section0.xml` (그리기 개체 및 텍스트)
   - `BinData/` (문서 포함 이미지 일체 정합성)
2. **7개 언어군 폰트 매핑**:
   - KS X 6101 표준이 명시한 7대 언어(`hangul`, `latin`, `hanja`, `japanese`, `other`, `symbol`, `user`) 블록을 모두 생성하여 한컴오피스 열기 시 서체 누락 경고 배제.
3. **수동 검증 권장 절차**:
   - 사용자가 한컴오피스 한글 2020/2024 GUI에서 `canvas_report1.hwpx`, `canvas_report2.hwpx`, `canvas_report3.hwpx`를 열어 대화상자 승인 후 시각적 레이아웃과 텍스트 편집 기능을 확인 가능함.

## 6. 잔여 한계 및 향후 개선 과제

1. **VML 특수 도형 지원 확장**:
   - 사각형, 둥근 사각형, 라인은 100% 지원되나 복잡한 벡터 폴리곤/베지어 곡선은 기본 사각형 바운딩 박스로 폴백됨.
2. **복수 페이지 HWPX 구획(Section) 고도화**:
   - 현재 단일 섹션 내 페이지 브레이크 방식을 취하고 있으며, 각 페이지별 고유 바탕쪽/머리말 구획 분리는 Phase 14 과제로 남김.
3. **Word COM 스크린샷 자동화 CI 통합**:
   - Word COM PDF 변환은 성공적으로 확인되었으므로, 차후 PDF → PNG 변환 도구를 파이프라인에 연결하면 무인 시각적 회귀 감사가 가능함.
