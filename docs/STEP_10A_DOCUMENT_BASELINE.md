## 7. 발견된 문제점 우선순위 (P0 ~ P3)

### [P0] 다중 프레임 캔버스 변환 시 문서형과 비문서형 프레임 혼재
- **증상**: 캔버스 내에 A4 프레임(595px)과 대형 웹/모바일 프레임(1200px)이 함께 존재할 때, 전체가 하나의 Word 문서(16페이지)로 합쳐지며 문서 전체가 세로형 A4로 고정됨.
- **영향**: 순수 A4 문서만 변환하려는 사용자의 의도와 달리 비문서 프레임이 앞뒤로 끼어듦.

### [P1] 순수 벡터/도형 기반 차트(`VECTOR`, `RECTANGLE`) 렌더링 누락
- **증상**: A4-3 프레임의 막대 차트처럼 여러 `VECTOR` 선과 절대좌표 `RECTANGLE` 막대로 조합된 그래픽이 Word 표나 이미지로 변환되지 않고 무시됨.
- **영향**: 차트가 포함된 보고서 페이지가 빈 페이지처럼 출력됨.

### [P1] Web UI 가로형(Landscape) 다운로드 시 파일 동일 생성 버그
- **증상**: `testnewpagePortrait.docx`와 `testnewpageLandscape.docx`의 해시가 완전히 동일하며, 둘 다 세로형(`orient="portrait"`)으로 저장되어 있음.
- **원인 추정**: 웹 UI에서 가로형 모드로 변환을 재실행하지 않고 다운로드했거나, 변환 옵션이 파이프라인에 즉시 전달되지 않는 UI 상태 동기화 이슈.

### [P2] 컴포넌트 내 미세 벡터 아이콘 미표시
- **증상**: 검색 돋보기, 옵션 체크마크 등 10~15px 크기의 단일 벡터 아이콘이 비어 있는 공간으로 남음.

### [P3] 단일 텍스트 상자 내 Heading 패턴 인식 부재
- **증상**: Figma에서 줄바꿈으로만 구분된 텍스트(`Page 1: 표지`, `1. 주요 성과`)를 자동으로 Word 제목(`Heading`) 스타일로 승격시키지 못함.
