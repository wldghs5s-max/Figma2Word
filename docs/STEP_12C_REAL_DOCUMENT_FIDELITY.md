# Figma2Word — Step 12C: 실제 3종 보고서 기반 시각적 충실도 측정 및 핵심 레이아웃 개선 보고서

## 1. 개요 및 작업 배경

Figma2Word는 Figma 디자인 및 JSON 스냅샷을 결정론적 파이프라인(Parser → IR → Layout Engine → DOCX Renderer)을 통해 편집 가능한 고품질 Microsoft Word 문서(.docx)로 변환하는 오픈소스 로컬 도구입니다.

Step 12B에서 구축된 실제 업무용 보고서(1차, 2차, 3차) 기준 자료와 Step 12A 품질 감사 인프라(Word COM 자동 렌더링 및 픽셀/구조 비교 엔진)를 바탕으로, 본 Step 12C에서는 **실제 3종 보고서의 라이브 변환 충실도 측정 및 실무 문서 핵심 레이아웃 결함 개선**을 완료하였습니다.

## 3. 핵심 시각적 결함 분석 및 해결 내역

### 3.1. 결함 1: 최상위 A4 페이지 프레임의 1x1 중첩 테이블 래핑 해제 (Nested Table Imprisonment 해소)
- **원인 분석**:
  - Figma의 각 페이지는 A4 크기(`794 × 1123 px` = Word A4 `595.5 × 842.25 pt`)의 루트 `FRAME`으로 구성되어 있습니다.
  - 기존 렌더러는 배경색이나 자식을 가진 컨테이너를 기본적으로 Word 1x1 `Table`로 감싸는 카드로 취급했습니다.
  - 이로 인해 1차 보고서 9개 페이지 내부의 **63개 데이터 표(Data Table)** 전체가 1x1 중첩 테이블(`Nested Table`) 내부에 갇혀, Word 렌더링 엔진의 셀 여백과 테이블 바깥 여백이 이중으로 중첩되고 페이지 넘김이 왜곡되었습니다.
- **해결 방안 (`src/renderer/docxRenderer.ts`)**:
  - A4 다중 페이지 문서(`isA4Doc && hasPageBreaks`)에서 최상위 섹션 요소 중 페이지 아트보드 컨테이너(`width >= 500` 또는 full-size)를 1급 흐름 요소(Paragraph, Table, Image)로 직접 언래핑(`effectiveElements`)하여 문서 본문에 직렬화했습니다.
  - 독립 모바일 화면(`width < 500`)은 개별 카드 래핑을 보존하여 기존 모바일 화면 격리 사양과의 무회귀를 보장했습니다.

### 3.2. 결함 2: 연속 요소 간 간격(`gap`)의 빈 단락 누적 제거 (Gap Absorption)
- **원인 분석**:
  - 기존 `renderSequence`는 컨테이너의 `gap` 속성을 처리할 때 요소 사이에 `new Paragraph({ spacing: { before: gap } })`를 빈 단락으로 삽입했습니다.
  - Word OpenXML 특성상 텍스트가 없는 빈 단락도 최소 기본 줄높이(약 12~14pt)를 차지하므로, 페이지당 수십 개의 빈 단락이 누적되어 하단 푸터 바나 마지막 표가 다음 장으로 강제 밀려났습니다 (18페이지까지 부풀려진 주원인).
- **해결 방안 (`src/renderer/docxRenderer.ts`)**:
  - 직전 요소가 단락(`ParagraphElement` 또는 `HeadingElement`)인 경우, 불필요한 빈 단락을 생성하지 않고 직전 단락의 `spacing.bottom`에 간격 값을 직접 흡수(absorb)하도록 최적화했습니다 (`bottom = Math.max(existing, gap)`).
  - 이를 통해 페이지당 수백 pt의 수직 누적 오차를 결정론적으로 제거했습니다.

### 3.3. 결함 3: 표 셀 내부 콤팩트 패딩 및 A4 적응형 문서 여백 적용
- **원인 분석**:
  - 복합 데이터 표가 많은 보고서에서 각 표 셀 내부 단락이 기본 14pt 줄높이와 4pt 후여백을 가질 경우, 10~15행 표의 전체 높이가 A4 페이지 인쇄 한계를 초과하여 다음 페이지로 이월되었습니다.
- **해결 방안 (`src/renderer/docxRenderer.ts`, `src/parser/figmaParser.ts`)**:
  - 표 셀 내부 단락 렌더링(`renderCellElements`) 시 콤팩트 줄높이(11pt / 220 line) 및 후여백 0pt를 적용하고, 셀 내부 패딩을 1.5pt/3pt로 최적화했습니다.
  - A4 스크린 감지 시 인쇄 적응형 여백(`top: 5mm, right: 8mm, bottom: 5mm, left: 8mm`)을 자동 설정하여 Figma 캔버스의 넓은 작업 영역을 Word 가용 폭에 최적 맞춤화했습니다.
