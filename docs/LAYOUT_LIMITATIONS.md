# 레이아웃 전략 한계 분석 및 문제 분류 보고서 (LAYOUT_LIMITATIONS)

본 문서는 Figma2Word의 **레이아웃 변환 전략의 기술적 한계**와 **P0 ~ P3 문제 해결 상태 및 잔여 과제**를 명시한다.

---

## 1. 문제 해결 현황 요약 (Phase 3 완료 기준)

| 분류 | 항목 | 내용 | Phase 3 상태 |
|---|---|---|---|
| **P0** | 치명적 결함 | 파서 크래시, 손상된 DOCX 파일 생성 | **0건 (해당 사항 없음)** |
| **P1-1** | 좌우 병렬 수직 적층 | Non-Auto Layout 병렬 요소 수직 늘어짐 | **해결 완료 (Strategy E: Bounding Box Interval 클러스터링)** |
| **P1-2** | Z-index 오버레이 분리 | 카드 배경 사각형과 내부 텍스트 분리 | **해결 완료 (Strategy E: Containment Folding)** |
| **P1-3** | Fixed vs Fill 폭 왜곡 | Auto Layout 컬럼 1/N 균등 분할 왜곡 | **해결 완료 (Strategy E: Width 비율 기반 columnWidths 산출)** |

## 2. 해결된 P1 핵심 문제 상세

### 2.1 [P1-1 해결] Non-Auto Layout 좌우 병렬 요소 수평 클러스터링
- **기존 한계**: X축 인접성을 고려하지 않고 Y축 단일 정렬만 수행하여 좌우 컬럼이 위아래로 떨어짐.
- **해결 방식**: `clusterHorizontalRows` 알고리즘을 도입하여, Y축 겹침(Overlap) 비율이 임계치 이상인 인접 형제 노드들을 가상 수평 컨테이너(`layoutMode: 'HORIZONTAL'`)로 묶고 X 좌표 오름차순으로 정렬.
- **결과**: 절대 좌표 기반의 2열, 3열, 혼합 흐름 디자인이 Word 다열 테이블로 올바르게 변환됨.

### 2.2 [P1-2 해결] Z-index 오버레이 노드의 카드 폴딩
- **기존 한계**: 배경 사각형과 그 위에 얹힌 텍스트가 순차 블록으로 쪼개져 카드가 해체됨.
- **해결 방식**: `foldContainedOverlays` 알고리즘을 도입하여 배경 노드의 바운딩 박스 안에 포함된 형제 노드들을 배경 노드의 자식으로 이동(Folding)시키고 프레임 컨테이너로 승격.
- **결과**: Word에서 단일 음영 카드(Container Table) 내부에 텍스트가 안착되어 시각적 일체감 보존.

### 2.3 [P1-3 해결] Auto Layout Sizing Mode (Fixed vs Fill) 가중치 반영
- **기존 한계**: 자식 개수 $N$에 따라 무조건 $100\% / N$으로 균등 분할되어 40px 아이콘이 50% 폭을 차지함.
- **해결 방식**: `enrichSizingRatios` 알고리즘을 통해 자식 노드들의 바운딩 박스 폭을 기준으로 정규화된 백분율 폭(`columnWidths`)을 산출하여 IR에 전달.
- **결과**: 아이콘과 텍스트가 실제 디자인 비율(예: 20% vs 80%)에 맞추어 Word 셀에 할당됨.

## 3. 남은 기술적 한계 (Known Limitations)

### 3.1 부분 겹침 (Partial Overlap / Broken Grid)
- 한 노드가 다른 노드의 경계선에 반만 걸쳐 있는 디자인(예: 아바타 이미지가 헤더 배너의 하단 테두리에 반쯤 걸친 경우)은 완전 포함(Containment)이 아니므로 폴딩되지 않고 분리될 수 있음.
- **대안**: 향후 복합 2D 그리드 추론(Strategy C의 간소화 버전) 또는 상단 마진 보정 휴리스틱 검토.

### 3.2 극단적 지그재그 높이 차이 (Staggered Layout)
- 핀터레스트 스타일의 메이슨리(Masonry) 레이아웃이나 높이가 들쭉날쭉한 비정형 배치의 경우 행 단위 클러스터링으로 표현하기 어려움.
- **대안**: 비즈니스 문서/보고서에서는 드문 패턴이므로 현재 범위에서는 지원 외 한계로 규정.

### 3.3 Word OpenXML 네이티브 한계 (수용적 제약)
1. **Word Table 모서리 둥글기(Corner Radius)**: Word OpenXML 규격상 테이블 셀 모서리를 둥글게 깎는 기능이 지원되지 않음 (직각 유지).
2. **복합 그라디언트 및 블러 효과(Drop Shadow/Blur)**: Word 문단/테이블에서 완전한 CSS 드롭 섀도우를 렌더링할 수 없어 단색 괘선 또는 음영으로 근사함.
