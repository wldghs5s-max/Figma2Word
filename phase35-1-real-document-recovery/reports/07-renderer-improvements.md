## 1. 개요 및 원칙

Figma 디자인을 편집 가능한 Microsoft Word 문서로 변환할 때 발생하는 대표적 결함(텍스트 수직 지터링, 구두점 밀림, 극단적 종횡비 도형의 모서리 왜곡)을 해결하기 위해 도입된 3대 구조적 개선 사항의 코드 수준 분석 및 보존 내역입니다.

**절대 원칙**: 특정 `nodeId`나 고객사 화면명을 하드코딩한 규칙은 0건이며, 100% 범용 OpenXML 및 VML 기하학 규칙만으로 구현되었습니다.

## 2. 3대 구조적 개선 상세

### 2.1 문서 격자 스냅 비활성화 (`<w:snapToGrid w:val="0"/>`)
- **원인 분석**:
  - Microsoft Word는 기본적으로 페이지에 설정된 12pt 문서 격자에 텍스트 문단을 강제 정렬하려는 성질이 있습니다.
  - 이로 인해 Figma 원본에서 정밀하게 서브픽셀 단위로 중앙 정렬된 버튼이나 입력창 내부의 텍스트가 위아래로 2~4pt씩 튀는(Jittering) 시각 왜곡이 발생했습니다.
- **코드 조치**:
  - `src/canvas/renderer/docxCanvasRenderer.ts`의 문단 속성(`w:pPr`)에 `<w:snapToGrid w:val="0"/>`을 상시 추가하여 Word 레이아웃 엔진의 임의 수직 스냅을 차단했습니다.

### 2.2 구두점 오버플로우 방어 (`<w:overflowPunct w:val="0"/>`)
- **원인 분석**:
  - 행 끝에 마침표(`.`), 쉼표(`,`), 괄호(`)`) 등 CJK 구두점이 올 때, Word 기본 줄바꿈 알고리즘이 오른쪽 여백을 밀어내며 불필요한 자동 줄바꿈을 유발했습니다.
- **코드 조치**:
  - `w:pPr`에 `<w:overflowPunct w:val="0"/>`을 선언하여 텍스트박스 내부 너비를 초과하여 글자가 아래 행으로 밀리는 현상을 억제했습니다.

### 2.3 VML ArcSize 분모 안전 가드 (`minDim > 0`)
- **원인 분석**:
  - 높이가 매우 얇은 가로선이나 버튼 테두리에서 `minDim = Math.min(width, height)`가 0 또는 극단적으로 작은 값이 될 때, `2 * r / minDim` 연산에서 분모가 0이 되어 `Infinity` 또는 `NaN`이 XML 속성으로 방출될 위험이 존재했습니다.
- **코드 조치**:
  - `minDim > 0 ? scalarRadius / minDim : 0` 안전 삼항식을 적용하여 어떠한 극단적 기하학 종횡비에서도 규격 준수 `arcsize` 값을 보장했습니다.
